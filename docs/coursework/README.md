# Coursework records

Fairshare supports two separate BUSFIN 4215 submissions: Venture MVP (10%) and Pitch 1 (5%). Solo groups are allowed, but each assignment uses its own Canvas group set.

| Record                              | Purpose                                                                            |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| [Experiment](experiment.md)         | Customer, hypothesis, precommitted criteria, decision rules, and consent           |
| [Test protocol](test-protocol.md)   | Five-minute participant session and anonymous observation fields                   |
| [Economics](economics.md)           | Pricing assumptions, contribution, acquisition, sensitivity, and cash implications |
| [Evidence](evidence.md)             | Actual participant results and limits                                              |
| [Build log](build-log.md)           | Implementation history, AI assistance, verification, and ownership                 |
| [Revision record](revision.md)      | Changes prompted by evidence and their verification                                |
| [Pitch slides](pitch.pptx)          | Three-slide PowerPoint with public product URL                                     |
| [Pitch script](pitch-script.md)     | Timed narrative and live demonstration                                             |
| [Pitch revision](pitch-revision.md) | Actual advice and claim revision after practice                                    |

## Current evidence

One informal test by a friend has been reported; the formal study and pitch practice remain pending. The evidence and revision records therefore remain incomplete. A working deployment does not establish demand, user adoption, or a completed practice/re-pitch sequence.

## Submission requirements

Venture MVP: submit the public product URL, source, experiment, ethical evidence with a denominator, economics, build log, and revision record before the enrolled section begins.

Pitch 1: give the ungraded 90-second pod practice, receive advice, revise, and give the graded 90-second re-pitch. Submit the slides actually used as PDF or PowerPoint, the public product URL, and a short note identifying the claim revised after practice. Include a shareable deck link only if a live deck was used.
